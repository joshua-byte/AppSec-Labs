# AppSec Labs

Hands-on application security labs built to practice vulnerability discovery, exploitation, secure coding, remediation, and verification.

The goal of this repository is to document practical application security work rather than simply list security concepts or tools.

---

## Learning Workflow

Each lab follows the same process:

```text
Learn
  ↓
Build Vulnerable Application
  ↓
Test / Exploit
  ↓
Identify Root Cause
  ↓
Remediate
  ↓
Re-run Application
  ↓
Verify Fix
  ↓
Document
